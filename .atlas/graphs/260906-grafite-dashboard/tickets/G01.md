# G01 · Font Grafite in variante incorporabile

> Ramo: Grafite a monte · Tipo: task · Modo: AFK
> Bloccato da: nessuno, prendibile subito
> Stato e dipendenze vivono in `../graph.json`, e si cambiano solo con uno script di mutazione.

## Domanda

Nella repo Grafite (~/cristiano/30-resources/33-design/grafite (repo strawberry-code/grafite-theme, v1.1.0)) il foglio dist/grafite.css tira i tre caratteri da Google Fonts con un @import. La dashboard di Atlas e' un file solo che si apre da disco anche senza rete, quindi quell'@import li' non puo' arrivare.

Produci in Grafite una variante incorporabile: subset latino di Inter (400/500/600), Space Grotesk (400/500/700) e JetBrains Mono (400/500), ciascuno come @font-face con src in data:font/woff2;base64. I woff2 di partenza stanno gia' nella copia di luglio in ~/cristiano/10-projects/17-web-apps/grafite-design-system/fonts/. Lo script che genera il subset resta nella repo, perche' la variante dev'essere rigenerabile e non un blob committato una volta e mai piu' riproducibile.

E' fatto quando: dist/grafite.fonts.inline.css esiste, non contiene nessun URL remoto, una pagina HTML di prova che linka solo quel foglio mostra i tre caratteri giusti, e il peso totale del foglio sta sotto i 400KB.

## Risposta

Prodotto: `dist/grafite.fonts.inline.css`

**Tagli inclusi:** Inter 400/500/600, Space Grotesk 400/500/700, JetBrains Mono 400/500.

**Peso totale:** 203.25 KB (well sotto i 400 KB). Ogni `@font-face` contiene `font-display: swap` e `src:url(data:font/woff2;base64,...)`, nessun URL remoto.

**Verifiche tecniche:**
- Tutti e 8 i file WOFF2 hanno magic number valido (`WOFF2`).
- Il CSS contiene 8 definizioni `@font-face` con i corretti `font-family` (Inter, Space Grotesk, JetBrains Mono) e `font-weight`.
- Assenza di URL remoti verificata (grep su `http` e `//fonts.`).
- Rigenerazione idempotente: tre esecuzioni consecutive di `build-fonts-inline.mjs` producono file identici.

**Verifica visuale (screenshot headless Firefox 1280x1600):**
- **I tre caratteri sono visibilmente diversi:** Inter sans-serif neutro, Space Grotesk grottesco geometrico squadrato, JetBrains Mono monospazio con spazi fissi.
- **Accenti italiani perfetti:** à è é ì ò ù À È É Ì Ò Ù - tutti visibili, nessun rettangolo.
- **Simboli Atlas (monospazio):** ▲ ⬅ ✓ · ✕ ⌖ ↑ → - tutti caricati correttamente in JetBrains Mono.
- **Token CSS funzionanti:** --sans (Inter), --display (Space Grotesk), --mono (JetBrains Mono) si applicano correttamente.
- Screenshot: `docs/screenshots/fonts-inline-verification.png`

**Rigenerazione:**
1. I sorgenti font stanno in `grafite/fonts/` (8 file woff2, ~152 KB).
2. Lo script `build-fonts-inline.mjs` legge i file e genera il CSS con base64 inline.
3. Per rigenerare: `node build-fonts-inline.mjs` da `grafite/`.
4. Comando documentato nel README.md sezione «Versione completamente offline con font incorporati».
