# G02 · Variante offline di grafite.css

> Ramo: Grafite a monte · Tipo: task · Modo: AFK
> Bloccato da: G04
> Stato e dipendenze vivono in `../graph.json`, e si cambiano solo con uno script di mutazione.

## Domanda

Deriva da dist/grafite.css la variante che Atlas puo' incorporare: stessa cosa senza l'@import di Google Fonts, con i token --sans/--display/--mono lasciati come punto di aggancio, esattamente come suggerisce il commento in testa al foglio.

Va derivata, non riscritta a mano: una copia scollegata diverge alla prima modifica di grafite.css. Se serve un passo di generazione, mettilo nella repo accanto a quello dei font.

E' fatto quando: dist/grafite.offline.css non contiene nessun URL remoto, e a parte l'@import e' identico a dist/grafite.css.

## Risposta

### Cosa è stato fatto

Derivata `dist/grafite.offline.css` da `dist/grafite.css` con uno script di generazione automatica, non manuale. Lo script:

1. Legge `dist/grafite.css` integralmente
2. Rimuove la riga di `@import url('https://fonts.googleapis.com/...')`
3. Mantiene il commento di intestazione che spiega il punto di aggancio (i tre token `--sans`, `--display`, `--mono`)
4. Aggiunge un header che spiega la generazione e come rigenerare
5. Scrive `dist/grafite.offline.css`

Lo script vive in `build-offline.mjs`, eseguibile con `node build-offline.mjs`.

### Verifiche completate

- ✓ `dist/grafite.offline.css` non contiene `@import url` né `fonts.googleapis`
- ✓ È identico a `dist/grafite.css` tranne che per la riga rimossa
- ✓ Contiene tutte le ricette di superfici dense (`.text-xs`, `.label-xs`, `.metric-sm`)
- ✓ Contiene tutte le ricette canvas (`.gf-node`, `.gf-edge-*`, `.gf-controls`, `.gf-minimap`)
- ✓ File idempotente: rigenerare due volte non cambia il contenuto
- ✓ Propagazione verificata: una riga di test aggiunta a `grafite.css` è comparsa nella variante offline dopo la rigenerazione, e sparita quando il file è stato ripristinato

### Documentazione

Aggiunto nel `README.md` della repo Grafite una sezione "Uso offline" che spiega:
- Come importare la variante offline
- Come sovrascrivere i token tipografici se si servono i font da sé
- Come rigenerare lo script

### Politica di manutenzione

D'ora in poi, ogni volta che `dist/grafite.css` viene modificato:
1. Chi modifica il file lanciare `node build-offline.mjs` prima di committare
2. Oppure l'automazione (se configurata) lo fa al commit/push
3. La sincronizzazione è garantita dallo script, non da copia-incolla manuale

### Scelte non canoniche

Nessuna. Lo script è determinato dal requisito "non derivato a mano" e dalla necessità di zero dipendenze aggiuntive (stdlib Node sola).
